# CPP Module 07 — Templates

This repository contains **CPP Module 07** exercises, focused on C++ templates.

## 📚 Module Overview

In this module, the main goal is to understand and practice:

- Function templates
- Class templates
- Generic programming in C++
- Type-safe reusable code

## 🧩 Exercises

Typical module content includes:

- **ex00**: Generic `swap`, `min`, and `max`
- **ex01**: Generic `iter` function
- **ex02**: Templated dynamic array class

## 🛠️ Build & Run

From an exercise directory (for example `ex00/`):

```bash
make
./<program_name>
```

If available:

```bash
make clean
make fclean
make re
```

## ✅ Compilation Rules

Projects in this module are usually compiled with:

- `c++`
- `-Wall -Wextra -Werror`
- `-std=c++98` (or the subject-required standard)

## 🎯 Learning Outcome

By completing this module, you should be comfortable writing reusable and type-independent C++ code using templates.
